# Weather-Trends

> Project about analyzing local and global temperature

### Setup (Optional)

For backend service you should install python packages and modules using the pip command:

```sh
$ pip install -r requirements.txt
```

The frontend of this project, written in Angular and you should run this command for serving the frontend app on your host:

```sh
$ cd web/frontend
$ npm install
$ ng serve
```

If you haven't started the backend service, you should run the frontend service in production mode.
Because, in this mode, all data which is required for building charts will be fetched from my host at Heroku.

```
$ ng serve --prod
```
